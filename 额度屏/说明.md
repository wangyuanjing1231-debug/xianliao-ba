# 额度屏 (微雪 ESP32-S3-LCD-1.54) · v2.0 三页全英文版

## 干什么

把微雪 ESP32-S3 1.54 寸方屏小板做成放在家里的 Gemini 专用额度屏：
1. **全英文极简界面**：彻底去掉了中文（避免缺字库乱码），每页只保留四个元素：一个大标题、一个大数字、一根进度条、一行重置时间。去掉 IP、账号档位等杂乱小字。
2. **三页滚动切换**：
   - **第 1 页 `5H`**（开机默认主页）：Antigravity Gemini 组 5 小时额度剩余百分比 + 离重置还有多久（如 `Resets in 3h 28m`）。
   - **第 2 页 `WEEKLY`**：Antigravity Gemini 组每周额度剩余百分比 + 重置倒计时（如 `Resets in 2d 12h`）。
   - **第 3 页 `GEMINI WEB`**：Gemini 网页版（gemini.google.com 独立配额池）额度，大数字显示 5 小时剩余百分比及重置时间，小字显示每周额度（如 `Weekly: 66% (Reset 10-20 13:14)`）。
3. **按键控制与自动归位**：
   - **左音量键 (GPIO 4 / PLUS)**：下一页。
   - **右音量键 (GPIO 0 / BOOT)**：上一页。
   - **主按键 (GPIO 5 / PWR)**：关报警。
   - **自动归位**：翻到第 2、3 页后 30 秒无人操作，自动切回第 1 页。
4. **三色预警与离线变灰**：
   - 剩余 > 50% 显示绿色。
   - 20% ~ 50% 显示黄色。
   - < 20% 显示红色。
   - 超过 3 分钟未取到新数据，整屏背景与条状变灰。
5. **声音预警与拍手/按键停响**：
   - 5 小时额度低于 20% 触发单窗口唯一一次报警（短响一声、停两秒循环）。
   - 停响间隙监听拍手，拍手或按板子任意键立刻停响，无人管 1 分钟自动停。
   - 0 点至 10 点夜间静音只变颜色。
6. **YJW 端宿主机服务**：
   - 后台检测 5 小时窗口重置，自动发送 `agy -p "hi"` 续期。
   - 后台通过 Playwright MCP / browser-cli 定时读取网页版额度（每 30 分钟）。
   - 提供可视化 Web 控制台与 JSON 接口。

## 怎么用

### 1. YJW 宿主机端

服务已作为 systemd 用户服务开机自启（端口 8888）：
- 打开小网页查看三组额度面板：浏览器访问 `http://127.0.0.1:8888/` 或 `http://192.168.6.170:8888/`
- 查看实时 JSON：`curl http://127.0.0.1:8888/api/quota`
- 触发测试报警：`curl http://127.0.0.1:8888/api/trigger-alarm`
- 清除测试报警：`curl http://127.0.0.1:8888/api/clear-alarm`
- 立即刷新网页版额度：`curl http://127.0.0.1:8888/api/refresh-web`

### 2. 板子端

板子已刷入固件，开机自动连接家庭 Wi-Fi `qianzhi`（默认 IP `192.168.7.221`）：
- 查看当前屏幕 ASCII 快照：`curl http://192.168.7.221/screen`
- 查看三页完整 ASCII 快照：`curl http://192.168.7.221/screen?all=1`
- 远程查看指定页：`curl "http://192.168.7.221/screen?page=2"`
- 远程切换板子屏幕页面：`curl "http://192.168.7.221/screen?switch=1&page=3"`
- 查看硬件实时状态 JSON：`curl http://192.168.7.221/status`
- 触发响铃测试：`curl http://192.168.7.221/alarm`

### 3. 实体按键操作说明

- **按左侧音量键 (GPIO 4)**：屏幕向后翻页（1 -> 2 -> 3 -> 1）。
- **按右侧音量键 (GPIO 0 / BOOT)**：屏幕向前翻页（3 -> 2 -> 1 -> 3）。
- **按中间主按键 (GPIO 5)**：报警响铃时按下即停响。
- **翻页后放着不动**：30 秒后屏幕自动切回第 1 页。
- **报警响铃时**：双手拍掌，或按板子任意一个键，响铃即停。
