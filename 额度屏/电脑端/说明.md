# 额度屏 · 电脑端数据服务说明

## 1. 这套程序是干什么的

微雪 ESP32-S3 额度屏（放在桌面上的小方屏）用于实时显示 Gemini 的配额剩余百分比和重置倒计时。  
但单片机算力有限且无法直接在网页中过登录验证，因此由跑在 **电脑（YJW）** 上的这套数据服务做“中继桥梁”：

1. **读取 Antigravity 额度**：读取本地 Antigravity CLI 的凭据，调用 Google 内部配额接口获取 Antigravity Gemini 的 5 小时配额与每周配额；
2. **抓取 Gemini 网页版额度**：通过本地 Playwright MCP 服务与 Chrome 浏览器的持久化登录状态（`playwright-chrome-profile`），定时访问 `https://gemini.google.com/usage` 解析出网页端 5 小时与每周额度；
3. **开机自启与局域网供给**：在电脑本机 `0.0.0.0:8888` 端口提供 HTTP 接口，让额度屏在局域网（192.168.7.x）随时拉取最新 JSON 数据；
4. **窗口重置自动续期**：后台检测 5 小时窗口重置时，自动触发一次 `agy -p "hi"`，免去手动发消息唤醒。

## 3. 怎么启动与停止

服务已配置为 systemd 用户服务，日常无需手动启停。若需运维，可用以下命令：

```bash
# 1. 查看运行状态
systemctl --user status quota-service
systemctl --user status playwright-mcp

# 2. 启动服务（注意：quota-service 依赖 playwright-mcp 提供网页端抓取支持）
systemctl --user start playwright-mcp
systemctl --user start quota-service

# 3. 停止服务
systemctl --user stop quota-service
systemctl --user stop playwright-mcp

# 4. 重启服务
systemctl --user restart quota-service

# 5. 查看实时日志
journalctl --user -u quota-service -f
```

## 4. 开机怎么自己起来

本服务依赖 systemd 用户级守护进程。开机自启依赖两点配置：

1. **启用 systemd user 单元**：
   ```bash
   systemctl --user enable playwright-mcp
   systemctl --user enable quota-service
   ```
2. **开启用户驻留（User Lingering）**：
   Linux 默认在用户没有图形桌面或 SSH 登录时不会启动该用户的 systemd 实例。必须开启 linger，机器开机即使未登录用户，后台服务也会立即跑起来：
   ```bash
   sudo loginctl enable-linger yjw
   ```

## 5. 坏了怎么照着恢复（全新机器/重装步骤）

如果电脑系统重装、换机器或配置丢失，照着以下步骤即可完整复原：

### 第一步：安装系统依赖
```bash
sudo apt update
sudo apt install -y python3 python3-pip nodejs npm google-chrome-stable jq curl

# 安装全局 playwright-mcp
sudo npm install -g @modelcontextprotocol/server-playwright playwright-mcp
# 安装 MCP SDK（供 browser-cli 使用）
sudo npm install -g @modelcontextprotocol/sdk
```

### 第二步：恢复服务代码与脚本
```bash
# 1. 创建程序目录并复制主脚本
mkdir -p /home/yjw/quota-service/browser-shim
cp quota_service.py record-login-link.sh /home/yjw/quota-service/
cp browser-shim/* /home/yjw/quota-service/browser-shim/
chmod +x /home/yjw/quota-service/record-login-link.sh /home/yjw/quota-service/browser-shim/*

# 2. 复制命令行辅助工具与启动脚本
mkdir -p /home/yjw/.local/bin
cp playwright-mcp-server.sh /home/yjw/.local/bin/
chmod +x /home/yjw/.local/bin/playwright-mcp-server.sh

sudo cp browser-cli /usr/local/bin/
sudo chmod +x /usr/local/bin/browser-cli
```

### 第三步：恢复 systemd 服务配置
```bash
mkdir -p /home/yjw/.config/systemd/user/quota-service.service.d

cp systemd/quota-service.service /home/yjw/.config/systemd/user/
cp systemd/quota-service.service.d/no-browser-popup.conf /home/yjw/.config/systemd/user/quota-service.service.d/
cp systemd/playwright-mcp.service /home/yjw/.config/systemd/user/

# 重载 systemd 用户守护进程
systemctl --user daemon-reload
systemctl --user enable playwright-mcp quota-service
sudo loginctl enable-linger yjw
```

### 第四步：初始化浏览器登录态
网页版额度抓取需要 Chrome profile 中存有 Google 账号登录态：
```bash
# 以该 profile 临时打开一次 Chrome 浏览器
google-chrome --user-data-dir=/home/yjw/playwright-chrome-profile https://gemini.google.com/usage
# 在弹出的 Chrome 窗口中登录你的 Google 账号，确认能正常看到 Usage 额度页面后关闭浏览器。
```

### 第五步：启动并验证
```bash
systemctl --user restart playwright-mcp
systemctl --user restart quota-service

# 验证接口响应
curl http://127.0.0.1:8888/api/quota
```
如果返回带有 `gemini_5h_remaining_pct` 和 `gemini_web_5h_remaining_pct` 的 JSON 数据，并且额度屏显示正常数值，说明已彻底恢复。
