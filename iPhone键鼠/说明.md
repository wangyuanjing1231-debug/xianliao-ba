# iPhone 投屏与 USB 键鼠控制 (iPhone 16 Pro · iOS 26.1)

基于开源项目 [onehumanbeing/esp32-iphone-agent](https://github.com/onehumanbeing/esp32-iphone-agent) 的 `v0.1.0` 标签版本（"电脑在中间"架构：iPhone 经 AirPlay 投屏到电脑上的 UxPlay；ESP32-S3 插在 iPhone 的 USB-C 口作为标准 USB 鼠标加键盘，通过 Wi-Fi 听电脑指挥）。

原样使用官方开源代码，不改动上游代码。服务端和微雪 ESP32-S3 固件已部署完毕，开机自启。

---

## 硬件与网络架构

- **电脑 (YJW)**: IP `192.168.6.170`，运行项目 Python 服务端（端口 `8890`）与设备监听端口（`7300`），并拉起 UxPlay 接收 AirPlay 镜像（广播名：`iPhone Agent`）。
- **板子**: 微雪 1.54 寸 ESP32-S3R8（16MB Flash, 8MB PSRAM, 原生 USB），开机连入 Wi-Fi `qianzhi`（获取 IP `192.168.7.221`），并自动反向长连接 YJW 服务端 `192.168.6.170:7300`。
- **手机**: iPhone 16 Pro (iOS 26.1)，通过 USB-C 对 USB-C 线连接微雪 ESP32-S3 板子（板子由手机供电），开启 iOS 辅助触控后识别为 USB 鼠标+键盘。

---

## 快速使用（供 AI 与命令行调用）

本目录提供了命令实现工具 `iphone_ctl.py`，并在 `~/.local/bin/` 和 `~/bin/` 创建了快捷软链接，AI 或终端可直接运行：

### 1. 核心三条命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `iphone-shot` | `iphone-shot [保存路径.png]` | 截取当前 iPhone 镜像画面并保存为 PNG，标准输出返回文件绝对路径。若未投屏则明说原因。 |
| `iphone-tap` | `iphone-tap <x> <y>` | 按坐标点按。**支持截图绝对像素坐标**（如 `iphone-tap 350 720` 自动按画面分辨率换算归一化），也**支持 0~1 浮点比例**（如 `iphone-tap 0.35 0.52`）。利用项目内置的闭环指针修正。 |
| `iphone-type` | `iphone-type "英文内容"` | 在手机当前聚焦的输入框中键入 ASCII 英文字符串。 |

### 2. 顺手扩展的辅助命令

| 命令 | 用法 | 说明 |
|---|---|---|
| `iphone-swipe` | `iphone-swipe <x1> <y1> <x2> <y2>` | 滑动操作（支持像素坐标或 0~1 比例坐标）。 |
| `iphone-home` | `iphone-home` | 触发上滑手势回主屏幕。 |
| `iphone-back` | `iphone-back` | 触发左边缘右滑手势返回上一层。 |
| `iphone-key` | `iphone-key <key>` | 发送按键（如 `enter`, `space`, `esc`, `cmd+h` 等）。 |
| `iphone-ctl` | `iphone-ctl status` | 输出当前设备连线、投屏连线、校准状态的 JSON 数据。 |

## 用户在场时的操作步骤

电脑端服务端与板子固件已全部就绪。用户在手机旁时，按以下四步即可开始使用：

1. **接线**：把微雪 ESP32-S3 板子从电脑（YJW）上拔下，用一根双头 USB-C 线直接插到 iPhone 16 Pro 上（板子由 iPhone 供电，板子通电后几秒内自动连上 Wi-Fi `qianzhi` 并连入电脑服务端）。
2. **开启辅助触控**：对 Siri 说 **“打开辅助触控”**（或进入 iPhone【设置】→【辅助功能】→【触控】→【辅助触控】开启）。此时手机屏幕上会出现一个半透明的圆形鼠标指针。
3. **开始屏幕镜像**：在 iPhone 右上角下拉滑出【控制中心】，点击【屏幕镜像】图标，在设备列表中点击 **`iPhone Agent`**。
4. **控制面板完成校准**：
   - 在电脑浏览器打开网页控制面板：[http://192.168.6.170:8890/](http://192.168.6.170:8890/)
   - 确认左侧能看到 iPhone 的实时镜像画面，顶部状态显示板子已连接。
   - 点击界面上的 **【校准】**（或手动操控中的校准）。服务端会自动在屏幕上微移两次指针并闭环识别。若自动识别未命中，按页面提示用鼠标在画面上精确点击一下指针位置即可完成校准。
   - 校准只需做一次，校准数据保存在 `~/.hidagent/calibration.json`，重启依然有效。

## 服务管理命令

服务端已配置为 systemd 用户级守护进程（服务名：`esp32-iphone-agent.service`）：

- 查看服务状态：`systemctl --user status esp32-iphone-agent`
- 查看实时日志：`journalctl --user -u esp32-iphone-agent -f`
- 重启服务：`systemctl --user restart esp32-iphone-agent`
- 停止服务：`systemctl --user stop esp32-iphone-agent`

## 撤回办法（彻底卸载恢复原样）

如果后续不再使用这套系统，按以下步骤彻底撤回：

1. **停止并禁用后台服务**：
   ```bash
   systemctl --user stop esp32-iphone-agent.service
   systemctl --user disable esp32-iphone-agent.service
   rm -f ~/.config/systemd/user/esp32-iphone-agent.service
   systemctl --user daemon-reload
   ```

2. **删除命令行快捷方式**：
   ```bash
   rm -f ~/.local/bin/iphone-* ~/bin/iphone-*
   ```

3. **删除项目服务端与配置文件**：
   ```bash
   rm -rf /home/yjw/esp32-iphone-agent
   rm -rf ~/.hidagent
   ```

4. **将板子刷回原来的额度屏固件**：
   板子固件备份保留在 `xianliao-ba` 仓库中，进入 `xianliao-ba/额度屏/源码/edu_ping` 使用 arduino-cli 或 IDE 重新烧录即可。
