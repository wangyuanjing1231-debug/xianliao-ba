# iPhone 投屏与 USB 键鼠控制 (iPhone 16 Pro · iOS 26)

基于开源项目 [onehumanbeing/esp32-iphone-agent](https://github.com/onehumanbeing/esp32-iphone-agent)（`legacy` 分支）实现的“电脑在中间”自动化架构：
- **画面**：iPhone 经 AirPlay 屏幕镜像投屏到电脑端的 UxPlay（已升级至官方 1.73.7 正式版，采用软件解码）；
- **操作**：微雪 ESP32-S3 1.54 寸小板直插 iPhone USB-C 接口（由手机供电），作为免驱标准 USB 鼠标与键盘；
- **控制**：板子连入家庭 Wi-Fi 反向长连接电脑端 Python 服务端（`192.168.6.170:7300`），电脑端提供 Web 面板与一系列 `iphone-*` 命令行工具供 AI 或终端随时调用。

## 一、iPhone 上的必要设置（在场使用前必须配置）

为了保证电脑和 AI 能稳定控制真机，手机端只需做一次如下设置：

### 1. 开启“辅助触控”
- **路径**：iPhone【设置】→【辅助功能】→【触控】→【辅助触控】→ **开启**。
- **效果**：屏幕上会出现一个半透明的圆形鼠标光标。微雪板的鼠标移动指令通过控制该光标实现点按和滑动。

### 2. 把“鼠标右键”设定为“主屏幕”（关键！）
原版项目使用左上角甩动或上滑手势回桌面，在 iOS 26 上成功率低。我们在固件与服务端增加了 `rclick`（右键），并在 iOS 辅助触控中将其绑定为物理主屏幕键：
- **路径**：iPhone【设置】→【辅助功能】→【触控】→【辅助触控】→ **【设备】**。
- **配置**：
  1. 在设备列表中点击微雪板（显示为 `HID Bridge` 或鼠标设备）；
  2. 点击 **“自定附加按钮...”**；
  3. 弹出按键提示时，由电脑端发送一次右键（或插普通鼠标按右键，或已显示“按钮 2”/“右键”）；
  4. 将该按钮对应的操作分配为 **“主屏幕”**。
- **效果**：后续只要执行 `iphone-home`，板子就会给手机发送一次右键信号，真机瞬间回桌面，极度稳定。

### 3. 跟踪灵敏度与重新校准提醒
- **注意事项**：在辅助触控设置页面有一条 **“跟踪灵敏度”**（从乌龟到兔子的滑动条）。
- **必须重新校准**：**只要用户手动拉动过这个灵敏度滑块，鼠标光标在屏幕上的移动步长就会改变**。此时必须在控制面板重新点击一次【校准】（或按提示在画面上点一下光标），校准参数会自动持久化到电脑的 `~/.hidagent/calibration.json`，校准后即恢复精准点击。

## 二、快速使用指南

### 1. 接线与连接三步走
1. **插板子**：把微雪 ESP32-S3 板子插到 iPhone 底部 USB-C 口（手机供电，板子通电后几秒内自动连上 Wi-Fi `qianzhi` 并长连接电脑服务端）。
2. **确认辅助触控**：确保辅助触控处于开启状态（看到屏幕有圆圈光标）。
3. **开启屏幕镜像**：在 iPhone 右上角下拉滑出【控制中心】→ 点击【屏幕镜像】→ 选择 **`iPhone Agent`**。

### 2. 命令行工具（供 AI 与终端使用）
系统已内置全局软链接，终端直接输入即可：

| 命令 | 完整用法示例 | 作用说明 |
|---|---|---|
| `iphone-shot` | `iphone-shot` 或 `iphone-shot /tmp/screen.png` | 实时截取 iPhone 投屏画面并输出 PNG 文件绝对路径；未投屏会明确提示。 |
| `iphone-tap` | `iphone-tap 350 720`<br>`iphone-tap 0.35 0.52` | **点按坐标**。既支持截图上的绝对像素点，也支持 0~1 的比例坐标，内置闭环光标微调。 |
| `iphone-home` | `iphone-home` | **一键回主屏幕**（触发右键主屏幕功能，秒回桌面）。 |
| `iphone-type` | `iphone-type "Hello123"` | 在当前选中的输入框中键入 ASCII 英文字符与数字。 |
| `iphone-swipe` | `iphone-swipe 500 1200 500 400` | 从起点滑动至终点（支持绝对像素或 0~1 比例），用于上下翻页或左右滑屏。 |
| `iphone-back` | `iphone-back` | 从左侧边缘向右滑，触发 iOS 返回上一层手势。 |
| `iphone-key` | `iphone-key enter`<br>`iphone-key cmd+h` | 发送键盘按键或组合快捷键。 |
| `iphone-ctl` | `iphone-ctl status` | 输出当前设备连线、投屏连线、校准状态的 JSON 数据。 |

### 3. 网页控制面板
- **局域网访问（同 Wi-Fi 任意设备均可打开）**：[http://192.168.6.170:8890/](http://192.168.6.170:8890/)
- **本机访问**：[http://127.0.0.1:8890/](http://127.0.0.1:8890/)
- 提供实时画面查看、直接用鼠标在网页画面上点按真机、手动输入字符、一键校准、停止任务等功能。

### 4. 服务端后台守护进程管理
服务端运行在 systemd 用户级守护进程中：
- 查看运行状态：`systemctl --user status esp32-iphone-agent`
- 查看实时日志：`journalctl --user -u esp32-iphone-agent -f`
- 重启服务：`systemctl --user restart esp32-iphone-agent`
- 停止服务：`systemctl --user stop esp32-iphone-agent`

## 三、能用与不能用的边界（能力限制）

### 1. 能用的
- ✅ **真机画面实时感知**：毫秒级抓取投屏画面（8fps / 75 质量），可供视觉大模型（LLM/VLM）实时做目标检测与决策。
- ✅ **全屏幕高精度点按**：基于闭环微动修正的绝对坐标点按。
- ✅ **滑动手势**：上下滚动浏览微博/小红书/网页、左右滑切换页面等。
- ✅ **极速一键回桌面**：基于物理右键直接触发 iOS 桌面，无需复杂手势。
- ✅ **英文与数字输入**：原生 USB 键盘协议直接键入所有 ASCII 字符（大小写字母、数字、英文标点）。

### 2. 不能用的（使用前必读）
- ❌ **无法直接打中文汉字（只能打英文与数字）**：
  - 微雪板模拟的是免驱标准 USB HID 物理键盘，向手机发送的是硬件扫描码（ScanCode）。
  - iOS 针对外接物理键盘，无法像输入法软键盘那样直接由外设注入任意 Unicode 汉字文本；直接发送中文字符串会导致字符丢失或乱码。
  - *变通方案*：如需输汉字，需由脚本模拟逐字打出拼音并按空格选词，或在 Mac 配合 Universal Clipboard 剪贴板跨设备粘贴。当前直接调 `iphone-type` 仅支持英文和数字。
- ❌ **密码与部分版权保护画面不可见**：
  - iOS 系统在进入锁屏密码输入、Apple Pay、银行支付敏感控件、部分流媒体 DRM 视频时，AirPlay 镜像会自动黑屏屏蔽。这是苹果操作系统底层安全机制，无法通过截屏获取画面。
- ❌ **手机锁屏休眠限制**：
  - 手机如果长时间无操作进入锁屏休眠，AirPlay 投屏会自动断开，USB 接口也可能被系统挂起进入省电模式。自动化使用期间建议在 iPhone【设置】→【显示与亮度】中将“自动锁定”设为“永不”或保持屏幕唤醒。

## 四、相对项目原版（legacy 分支）改动明细

1. **固件（`hardware/hid_bridge/hid_bridge.ino`）**：
   - **键盘顺序在前**：颠倒了原版鼠标在前的声明与 `begin()` 顺序，优先注册键盘端点，解决 iOS 复合 HID 设备识别物理键盘问题；
   - **增加右键/中键**：添加 `rclick`（右键点击 60ms 释放）和 `mclick` 指令。
2. **服务端（`server/hidagent/`）**：
   - **`app.py`**：末尾增加 `POST /api/rclick` 路由；
   - **`screen.py`**：在拉起 UxPlay 进程时增加 `stdbuf -oL -eL`，解决 Python 管道标准输出缓冲导致日志延迟刷新的问题；加入 `-avdec` 强制采用 libavcodec 软件解码（避开 AMD VA-API 在 headless/无显示会话环境硬解崩溃），加入 `-d` 启用调试日志；
   - **UxPlay 升级**：从系统源旧版 `1.68` 换成官方源码编译安装的最新正式版 `v1.73.7`，解决 iOS 26 AirPlay 协议断流问题；
   - **`server/.env`**：增加 `HOST=0.0.0.0`，允许局域网设备访问控制面板。
3. **控制脚本（`iphone_ctl.py`）**：
   - 将 `cmd_home`（回主屏）原先调用 `/api/home` 改为调用 `/api/rclick`，与 iPhone 辅助触控右键功能完美对接。

## 五、怎么改回额度屏（恢复原状）

微雪这块小板原先是作为 Gemini 额度屏使用的。电脑端的额度屏数据取数服务（`quota-service`，端口 8888）一直完好运行，未受任何改动。

如果需要恢复为额度屏，按以下步骤操作：

1. **拔下板子插回电脑**：
   从 iPhone 拔下微雪 ESP32-S3 板子，插到 YJW 电脑的 USB 口上（识别为 `/dev/ttyACM0`）。
2. **重新烧录额度屏固件**：
   进入额度屏固件目录重新编译烧录：
   ```bash
   cd /home/yjw/work/xianliao-ba/额度屏/源码/edu_ping
   /home/yjw/.local/bin/arduino-cli compile -b esp32:esp32:esp32s3:USBMode=hwcdc,CDCOnBoot=cdc,FlashSize=16M,PSRAM=opi .
   /home/yjw/.local/bin/arduino-cli upload -b esp32:esp32:esp32s3:USBMode=hwcdc,CDCOnBoot=cdc,FlashSize=16M,PSRAM=opi -p /dev/ttyACM0 .
   ```
3. **停止 iPhone 键鼠服务（可选）**：
   ```bash
   systemctl --user stop esp32-iphone-agent.service
   systemctl --user disable esp32-iphone-agent.service
   ```
4. 板子烧录完成后重新插上供电，即可自动恢复为三页全英文 Gemini 额度屏。
