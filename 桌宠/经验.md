# 桌宠经验

- 屏幕引脚差异：Pocket-Dongle-S3 屏幕引脚与原版 T-Dongle-S3 完全不同（MOSI 11、SCLK 10、CS 12、DC 13、RST 14），背光硬接 3.3V 无法通过 GPIO 控制。
- 屏幕对齐偏移：0.96 寸 160×80 屏横屏显示时，必须设置 `col_offset = 26, row_offset = 1`，否则底部会出现雪花马赛克，四边无法对齐。
- 红蓝通道反转：屏幕 ST7735S 驱动需开启 `bgr = true`；APA102 彩灯需按 `R, G, B` 字节序写入，否则红蓝颜色颠倒。
- 多板共存防误刷：多块 ESP32-S3 共存时端口号会漂移，必须使用唯一硬件路径 `/dev/serial/by-id/usb-Espressif_USB_JTAG_serial_debug_unit_3C:0F:02:D8:51:B8-if00` 烧录，核对 MAC 地址。
- 任务进度读取：手机端读 Antigravity 会话工作目录下的 Markdown 清单，正则匹配 `- [x]` 统计进度。必须只读本地文件，实测耗时 0.018ms，绝不能拖慢主进程。
- 手机换 IP 自动连：路由器 DHCP 可能会变，固件支持 UDP 局域网广播自动搜索手机 IP 并存进 NVS，免去每次重新配置。
- 换 Wi-Fi 免刷机：固件内置科室与家庭双 Wi-Fi 自动轮询；连不上或长按 BOOT 键开热点网页配网。
