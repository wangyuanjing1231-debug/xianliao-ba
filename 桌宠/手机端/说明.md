# 桌宠 · 手机端服务说明

## 1. 这套程序是干什么的

桌宠（ESP32-S3 0.96 寸屏幕小棒子 / 桌面宠物）放在桌面上，用来实时指示 Antigravity AI 当前的工作状态（例如：大眼睛动画、思考中 Thinking、工具执行中、任务清单进度 `3/5`、完成等）。

因为 AI Agent（Antigravity）跑在手机（Sony Xperia 5 II）的 Ubuntu 容器里，桌宠硬件板子需要向手机获取状态。这套手机端程序分为两大部分：

1. **桌宠后台中继服务 (`desk-pet-server.py`)**：
   - **UDP 8888 广播寻址**：桌宠板子开机或断网重连时，会向局域网广播发送 `DISCOVER` / `XPERIA` / `PET` 喊话。手机监听到喊话后，自动把手机的当前 IP 和 HTTP 端口回复给板子，板子从此记住手机地址，无需手动写死 IP。
   - **TCP 8088 HTTP 状态接口**：手机以极小内存开销提供 HTTP 服务。板子循环请求 `http://手机IP:8088/` 获取实时的状态 JSON。
2. **Antigravity 状态钩子与进度提取 (`agy-hook.py` & `agy-hook.sh`)**：
   - 当 Antigravity 开始干活（`SessionStart`、`PreInvocation`）、调用工具（`PreToolUse`、`PostToolUse`）、任务结束（`Stop`）时，系统自动触发此脚本；
   - 脚本极速读取 Antigravity 当前会话任务清单中的 Markdown 清单文件（匹配 `- [x]` 与 `- [ ]` 统计进度，如 `3/5`）；
   - 将当前最新状态原子写入 `/root/desk-pet-state.json`，供 `desk-pet-server.py` 读取。

## 2. 原始文件位置与清单

这套程序跑在 **Sony Xperia 5 II 手机（Ubuntu 24.04 chroot 容器，用户 root）**：

| 文件 / 配置 | 仓库中的归档位置 | 手机上的原始路径 | 说明 |
| :--- | :--- | :--- | :--- |
| `desk-pet-server.py` | `桌宠/手机端/` | `/usr/local/bin/desk-pet-server.py` | UDP 8888 寻址中继与 HTTP 8088 状态服务主程序 |
| `chroot-services.sh` | `桌宠/手机端/` | `/usr/local/bin/chroot-services.sh` | Ubuntu chroot 启动引导脚本（第 6 节启动桌宠服务） |
| `agy-hook.sh` | `桌宠/手机端/` | `/root/agy-hook.sh` | Antigravity 调用的 Shell 包装脚本 |
| `agy-hook.py` | `桌宠/手机端/` | `/root/agy-hook.py` | 状态事件解析与 `- [x]` 进度统计提取核心程序 |
| `agy-statusline.sh` | `桌宠/手机端/` | `/root/agy-statusline.sh` | 终端状态行打印辅助脚本 |
| `antigravity-settings.json` | `桌宠/手机端/` | `/root/.gemini/antigravity-cli/settings.json` | Antigravity 的 hooks 配置文件（注册事件监听） |
| `desk-pet-state.sample.json` | `桌宠/手机端/` | `/root/desk-pet-state.json` | 状态数据示例格式 |

## 3. 怎么启动与停止

平时连入手机的方式：
```bash
# 在电脑终端执行，使用 SSH 钥匙直接登录 Xperia 手机的 Ubuntu chroot
ssh xperia
```

### 1. 手动启停桌宠服务
```bash
# 查看服务是否在跑
ps -ef | grep desk-pet

# 启动服务（放入后台，日志打入 /var/log/desk-pet-server.log）
nohup python3 /usr/local/bin/desk-pet-server.py </dev/null >/var/log/desk-pet-server.log 2>&1 &

# 停止服务
pkill -9 -f "desk-pet-server.py"

# 测试接口输出
curl -s http://127.0.0.1:8088 | jq .
```

## 4. 开机怎么自己起来

手机开机自启是通过 **Termux:Boot -> 宿主引导脚本 -> Ubuntu chroot 引导脚本** 的链条实现的：

1. 手机开机，Android 系统拉起 Termux:Boot，执行自启动挂载并进入 Ubuntu 容器：
   ```bash
   chroot "$UBUNTU" /bin/su - root -c "/usr/local/bin/chroot-services.sh"
   ```
2. `/usr/local/bin/chroot-services.sh` 脚本在拉起 SSHD、Tailscale、OpenClaw 之后，第 6 节自动启动桌宠服务：
   ```bash
   # 6. 启动 DeskPet HTTP & UDP 服务 (端口 8088 & 8888)
   pkill -9 -f "desk-pet-server.py" 2>/dev/null || true
   nohup python3 /usr/local/bin/desk-pet-server.py </dev/null >/var/log/desk-pet-server.log 2>&1 &
   ```
因此只要手机开机进入系统，桌宠服务就会自动常驻在后台。

## 5. 坏了怎么照着恢复（手机刷机/重装恢复指南）

如果手机刷机、重装了 Ubuntu 容器或换了新手机，请按以下步骤恢复：

### 第一步：进入手机 Ubuntu chroot
```bash
ssh xperia
```

### 第二步：安装 Python 基础依赖
```bash
apt update
apt install -y python3 jq curl
```

### 第三步：恢复服务与引导脚本
```bash
# 1. 恢复桌宠主服务
cp desk-pet-server.py /usr/local/bin/desk-pet-server.py
chmod +x /usr/local/bin/desk-pet-server.py

# 2. 确保 /usr/local/bin/chroot-services.sh 包含桌宠启动项
# （如果恢复了整个 chroot-services.sh，记得 chmod +x /usr/local/bin/chroot-services.sh）
grep -q "desk-pet-server.py" /usr/local/bin/chroot-services.sh || cat << 'EOF' >> /usr/local/bin/chroot-services.sh

# 6. 启动 DeskPet HTTP & UDP 服务 (端口 8088 & 8888)
pkill -9 -f "desk-pet-server.py" 2>/dev/null || true
nohup python3 /usr/local/bin/desk-pet-server.py </dev/null >/var/log/desk-pet-server.log 2>&1 &
EOF
chmod +x /usr/local/bin/chroot-services.sh
```

### 第四步：恢复 Antigravity 状态钩子
```bash
# 1. 恢复钩子脚本
cp agy-hook.sh agy-hook.py agy-statusline.sh /root/
chmod +x /root/agy-hook.sh /root/agy-hook.py /root/agy-statusline.sh

# 2. 恢复 Antigravity 配置文件
mkdir -p /root/.gemini/antigravity-cli/
# 将 antigravity-settings.json 复制或合并进 /root/.gemini/antigravity-cli/settings.json
cp antigravity-settings.json /root/.gemini/antigravity-cli/settings.json
```

### 第五步：启动并验证
```bash
# 启动桌宠服务
nohup python3 /usr/local/bin/desk-pet-server.py </dev/null >/var/log/desk-pet-server.log 2>&1 &

# 1. 验证 HTTP 接口
curl http://127.0.0.1:8088
# 正常应返回形如 {"state": "idle", "progress": "", "step": 0, "summary": "Ready"} 的 JSON

# 2. 验证桌宠硬件
桌宠板子通电开机，确认板子能通过 UDP 广播自动发现手机并获取状态，屏幕出现眼睛表情并且彩灯亮起。
