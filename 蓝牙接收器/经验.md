# 蓝牙接收器经验

- ESP32-S3 只支持低功耗蓝牙，不支持经典蓝牙（耳机、音箱那种）。
- 分工：板子只当"无线电"（蓝牙控制器），配对、加密由 Ubuntu 自带的 BlueZ 做；电脑上用 `btattach` 把板子的串口接给 BlueZ。
- Ubuntu 的 ModemManager（上网卡管理服务）看见新串口会乱发命令，接之前先暂停它。
- 板子开机会往串口吐几行启动文字，先读 1 秒扔掉，不然接不上。
- `btattach` 只在运行时有效，拔插一次就得重做，系统不会记住。
- 配对记录跟接收器的地址绑定，换回别的接收器要重新配对。
- 刷之前先把整片 16MB 备份下来，刷回时优先用备份。
- 固件在 GitHub 上自动编译：开发沙盒连不上乐鑫的组件库，本地编不了。
- 编译配置写错的选项会被悄悄忽略，编译脚本里逐条核对了关键选项是否生效。
