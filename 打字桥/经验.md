# 打字桥经验

- 只要结果、不打算自己参与的活，用强模型。最早用国产弱模型写，中文输入一直不通；换 Claude Opus 重写才跑通。
- 一口气打长文，网页会失联。改成排队打字：网页请求只放进队列、马上回话，板子每轮只打一个字，中间抽空理网页。
- Alt 键会卡住：松开信号偶尔丢。每打一个字前后都补发"全部松开"。
- 中文用 Alt + 小键盘输 GBK 编码；英文也走 Alt 码，这样不受电脑输入法中英文状态影响。
- 编译设置选错（USB Mode 不是 USB-OTG），板子当不了键盘。
- 烧完要拔插一次，电脑才会把它认成键盘（按住 BOOT 插上是烧录模式，不会注册成键盘）。
- 发送没反应，先看手机是不是还连着板子热点。曾经因为 WiFi 断了排查了半天。
- 合规：对电脑来说它只是一个键盘，不装驱动、不联网；但芯片自带 WiFi 和蓝牙，医院通常按设备类别管，给同事用之前先跟信息科报备。
