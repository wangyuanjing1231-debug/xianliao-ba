# 探索总仓库

我自己的探索项目。每个项目一个文件夹，先看里面的 `说明.md`。给 AI 的规矩在 `AGENTS.md`。

| 项目 | 干什么 | 状态 | 当前成品 |
| --- | --- | --- | --- |
| 打字桥 | 手机连板子热点，在网页上输入文字，板子假装成 USB 键盘打进电脑 | 能用 | `打字桥/成品/打字桥-v1.bin` |
| 蓝牙接收器 | 让 Ubuntu 电脑通过这块板子用上低功耗蓝牙（给 Muse 用） | 能用 | `蓝牙接收器/成品/蓝牙接收器-v1.bin` |
| 小智语音 | 1.54 寸屏的语音对话小板子，试过科室版、官方版、Muse 版 | 已放弃 | 无，只留经验 |

## 硬件

- 打字桥和蓝牙接收器用的是同一块板：Pocket-Dongle-S3（ESP32-S3 N16R8，16MB）。换用途就重刷，刷法见 `蓝牙接收器/说明-Windows刷机.md`。
- 小智语音用的是微雪 ESP32-S3-Touch-LCD-1.54。
