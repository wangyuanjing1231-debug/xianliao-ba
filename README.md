# 探索总仓库

我自己的探索项目。每个项目一个文件夹，先看里面的 `说明.md`。给 AI 的规矩在 `AGENTS.md`。

| 项目 | 干什么 | 状态｜最近进展 | 当前成品 |
| --- | --- | --- | --- |
| 打字桥 | 手机连板子热点，在网页上输入文字，板子假装成 USB 键盘打进电脑 | 能用｜10-15 整理成新结构 | `打字桥/成品/打字桥-v1.bin` |
| 蓝牙接收器 | 让 Ubuntu 电脑通过这块板子用上低功耗蓝牙（给 Muse 用） | 能用｜10-15 整理成新结构，编译改到英文路径 | `蓝牙接收器/成品/蓝牙接收器-v1.bin` |
| 桌宠 | 手机旁显示 Antigravity 运行状态（动画大眼睛 + 进度数字 + 彩灯联动） | 能用｜10-17 换装大眼睛与任务清单进度，双 Wi-Fi 无感切换 | `桌宠/成品/桌宠-v1.bin` |
| 额度屏 | 微雪 1.54 寸屏三页全英文显示 Antigravity (5h/每周) 与 Gemini 网页版额度，支持按键翻页、拍手停响与自动续期 | 能用｜10-18 改成三页全英文、统一渲染与 /screen、实物验证通过 | `额度屏/成品/额度屏-v1.bin` |

## 硬件

- 打字桥、蓝牙接收器和桌宠用的是同一块板：Pocket-Dongle-S3（ESP32-S3 N16R8，16MB）。换用途就重刷，刷法见各项目说明。
- 额度屏用的是微雪 ESP32-S3-Touch-LCD-1.54 / ESP32-S3-LCD-1.54。
